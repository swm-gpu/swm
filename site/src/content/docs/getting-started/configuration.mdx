---
title: Configuration
description: API keys, storage credentials, and defaults.
---

swm stores configuration in `~/.config/swm/config.toml`.

## Provider API keys

| Provider | Config keys |
|----------|------------|
| RunPod | `runpod.api_key` |
| Vast.ai | `vastai.api_key` |
| Lambda Labs | `lambda.api_key` |
| AWS | `aws.access_key`, `aws.secret_key` |
| GCP | `gcp.project` (uses gcloud CLI auth) |
| Azure | `azure.subscription_id`, `azure.tenant_id` |
| CoreWeave | `coreweave.kubeconfig` |
| Vultr | `vultr.api_key` |
| TensorDock | `tensordock.api_key`, `tensordock.api_token` |
| FluidStack | `fluidstack.api_key` |

```bash
swm config set runpod.api_key sk-xxxxxxxxxxxx
```

## Storage credentials

| Provider | Config keys |
|----------|------------|
| Backblaze B2 | `b2.key_id`, `b2.app_key`, `b2.bucket` |
| AWS S3 | `s3.access_key`, `s3.secret_key`, `s3.bucket` |
| Google GCS | `gcs.hmac_access`, `gcs.hmac_secret` |

## Model provider API keys

`swm models` uses the same config file for model registry credentials:

| Provider | Config keys | Used for |
|----------|-------------|----------|
| HuggingFace | `hf.api_key` | gated/private repos, higher API limits |
| Civitai | `civitai.api_key` | gated/restricted models and authenticated downloads |

```bash
swm config set hf.api_key hf_xxxxxxxxxxxx
swm config set civitai.api_key civ_xxxxxxxxxxxx
```

You can also pass `--token` to `swm models info` or `swm models pull` for a
single command. HuggingFace environment variables (`HF_TOKEN`,
`HUGGING_FACE_HUB_TOKEN`) are used when no `hf.api_key` is configured.

## SSH keys

```bash
swm config set ssh.key_path ~/.ssh/id_ed25519
```

## Guard defaults

```bash
swm guard defaults --mode auto-down --idle-timeout 30 --poll-interval 300
```

## View all config

```bash
swm config list
```

Keys containing "key" or "secret" are automatically masked in output.
